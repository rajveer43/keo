# Getting help

- **Usage questions:** open a thread in [Discussions](https://github.com/rajveer43/keo/discussions), or an [issue](https://github.com/rajveer43/keo/issues) if Discussions is not enabled.
- **Bugs:** use the [bug report form](https://github.com/rajveer43/keo/issues/new?template=bug_report.yml).
- **Security problems:** see [SECURITY.md](SECURITY.md). Do not post them publicly.
- **Citing KEO:** use the DOI badge in the [README](README.md) or [CITATION.cff](CITATION.cff).
